# 💗 Birthday Surprise Website

Plain HTML + CSS + JavaScript.

## GIFs

Put these files inside `assets/`:

- `intro.gif` — opening
- `no.gif` — first NO
- `no2.gif` — second NO
- `no3.gif` — third NO
- `no4.gif` — fourth NO
- `final.gif` — final surprise

### NO behavior

First click on NO → `no.gif`

Second click on NO → `no2.gif`

Third click on NO → `no3.gif`

Fourth click on NO → `no4.gif`

Further NO clicks stay on the fourth scene with a playful message.

The user can accept at any point using the YES/accept button.
